# Gather & Table: fictional catering demo

A single static page by Austin AI Marketing Co. (www.austinaimarketingco.com) that shows what a mobile catering inquiry page could look like.

- Gather & Table is a **fictional** business. There are no real testimonials, prices or bookings.
- The inquiry form only shows a preview on the page. It **sends, stores and charges nothing**, and the page makes no network requests, runs no analytics and loads no third-party scripts.
- Use fictional details when trying it.
